# 个人主页方案总结

## 目标定位

个人主页用于放进递出的简历中，作为简历之外的补充入口。简历负责快速证明岗位匹配度和硬指标，主页负责展示更完整的职业叙事、脱敏项目复盘和个人侧面的可信度。

当前推荐使用 `masterPortfolio` 风格作为主方案，因为它更适合在一个页面里展示经历、能力、项目案例、荣誉和个人补充信息。

主页核心定位：

> 研发体系里的产品交付者：懂研发边界、懂业务落地，能把复杂中台需求、AI 应用和跨团队项目推进成稳定上线的产品结果。

## 页面结构

当前本地预览路径：

- 主入口：`portfolio-previews/index.html`
- masterPortfolio 首页：`portfolio-previews/masterportfolio/index.html`
- 兴趣副页：`portfolio-previews/masterportfolio/life/index.html`

masterPortfolio 首页包含：

- 首屏定位：研发体系里的产品交付者
- 能力栈：需求分析、版本交付、AI 应用、数据分析、BPMN/Figma、Python/Java、RAG/Agent、跨团队协同
- 经历：质量与流程 IT、华为云
- 项目案例：流程管理 SaaS 中台、AI 工单分析平台、自动化交付专项
- 荣誉与可信度
- 场外一面入口

首页已加入 3 个兴趣页入口：

- 顶部导航：`场外一面`
- 首屏按钮：`场外一面`
- 底部预告区：`进入兴趣页`

## 与简历的差异

简历写：

- 做过什么
- 结果是多少
- 是否匹配岗位关键词

主页写：

- 如何判断问题
- 如何拆需求、定优先级、协调资源
- 如何把用户反馈、数据、版本交付连接成闭环
- 为什么这些经验能迁移到目标岗位

主页不应该只是网页版简历，也不应该放公司内网截图、代码仓库或敏感系统信息。项目内容应采用脱敏案例复盘的方式表达。

建议每个项目案例遵循：

```text
背景：业务/组织复杂度是什么
问题：当时卡在哪里
我的角色：我负责什么决策和推动
方案：怎么拆需求、定优先级、协调研发/业务
结果：量化指标
可迁移能力：为什么这个经验适合新岗位
```

## 兴趣副页方案

兴趣页名称：`场外一面`

页面调性：克制二次元。保留职业主页质感，只加入轻量像素标签、贴纸感卡片、轻微霓虹/漫画分镜式视觉元素。不要做成过度花哨的生活相册。

兴趣页目的：

- 补充人格和表达力
- 展示组织力、团队协作、公众表达和生活热情
- 让面试官看到简历以外更立体的一面

兴趣页包含 3 个模块：

### 篮球队长与组织者

内容重点：

- 喜欢篮球
- 作为队长兼组织者
- 连续三年代表华为云参加公司一层篮球比赛
- 最高名次第四名

职业侧表达：

- 长期组织能力
- 团队协作
- 临场判断
- 抗压和目标感

### 音乐与舞台表达

内容重点：

- 喜欢音乐
- 连续两年在华为云年会上唱歌、rap

职业侧表达：

- 公众表达能力
- 信息组织能力
- 感染力
- 方案讲解和跨团队沟通的补充证据

### 家里的猫

第三模块已从 `food-acg` 改为 `cat`。

内容重点：

- 记录家里猫的日常
- 作为高强度工作之外的生活稳定器
- 保留松弛感和观察力

视觉标签：

- `Mood Manager`
- `Home QA Lead`
- `Stress Reducer`

## 媒体素材目录

后续上传照片和视频时，统一放到：

```text
portfolio-previews/assets/life/
```

推荐目录结构：

```text
assets/life/
  basketball/
    hero.jpg
    game-01.jpg
    game-02.jpg
    game-03.jpg
    basketball-highlight.mp4

  music/
    stage-01.jpg
    stage-02.jpg
    annual-party-rap.mp4

  cat/
    cat-hero.jpg
    cat-01.jpg
    cat-02.jpg
    cat-03.jpg
    cat-04.jpg
```

文件命名建议：

- 使用英文、小写、短横线
- 避免中文、空格、括号
- 图片优先使用 `.jpg` 或 `.webp`
- 视频优先使用 `.mp4`
- 视频建议控制在 20-60 秒短片

页面里当前是占位框。后续替换真实素材时，将对应 `.media-slot` 改成：

```html
<img src="../../assets/life/basketball/game-01.jpg" alt="篮球比赛照片" />
```

或：

```html
<video src="../../assets/life/music/annual-party-rap.mp4" controls></video>
```

注意：兴趣页位于 `portfolio-previews/masterportfolio/life/index.html`，因此从兴趣页引用 `assets/life/` 时路径应使用 `../../assets/life/...`。
